Unity Supabase
RPC Helper

A lightweight, SDK-free way to call Supabase Postgres functions from Unity.

Coming soon to the Unity Asset Store

A focused tool.
The essentials, included.

01 /
01

SDK-free requests

Call Supabase RPC functions using UnityWebRequest, without a dependency on the Supabase SDK.

02

JSON parameters

Send function parameters with a JSON parameter builder or supply raw JSON.

03

Flexible responses

Handle raw responses, UUIDs, strings, booleans, numbers, objects and arrays.

04

Authenticated calls

Optionally use a user access token for authenticated RPCs.

05

Request control

Structured PostgREST errors, with timeout and cancellation support.

06

Demo scene included

Explore the request and response workflow in the included runtime demonstration scene.
